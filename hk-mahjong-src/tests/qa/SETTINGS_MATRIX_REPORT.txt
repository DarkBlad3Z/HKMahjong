SETTINGS MATRIX COVERAGE
================================================================================

Dimensions tested:
  - minFan: {0, 1, 3, 5}                      (4 values)
  - payment: {'full', 'shared'}               (2 values)
  - unit: {'points', 'chips'}                 (2 values)
  - optional patterns: 3 sets
    * all-on: {kong, sevenPairs, luxurySevenPairs, knitted, lesserHonours, greaterHonours}
    * all-off: all disabled
    * kong-only: only kong enabled
  - aiLevel: {'easy', 'normal', 'hard'}       (3 values)

Total configurations: 4 × 2 × 2 × 3 × 3 = 144 distinct settings

Test case: 3 games per config × 144 configs = 432 games, 3,290 hands

================================================================================
CHECKS PERFORMED AFTER EVERY HAND
================================================================================

1. Payment Validation
   - Payments sum exactly to 0
   - For wins: payments match HKMJ.Scoring.payments() formula
   - Handles full/shared payment modes and points/chips units

2. Scoring Validity
   - evaluation.valid is true for all wins
   - Fan >= minFan unless blessing or flower win
   - Correct handling of Heaven/Earth/Man blessings (always valid)
   - Seven/Eight Flowers instant wins recognized

3. Optional Pattern Restrictions
   - When sevenPairs disabled: no sevenPairs pattern wins
   - When knitted disabled: no knitted pattern wins
   - When lesserHonours disabled: no lesserHonours pattern wins
   - When greaterHonours disabled: no greaterHonours pattern wins
   - When luxurySevenPairs disabled: no luxurySevenPairs items in scoring
   - When kong disabled: no kong items in scoring

4. Dealer Logic
   - Dealer stays after dealer win or draw
   - Dealer passes to (dealer+1)%4 otherwise
   - nextDealer field matches expected calculation

5. Anomaly Detection
   - Any exception raised by AI or engine
   - AI decision time > 250 ms (hard timeout for performance)
   - Games exceeding 60 hands (rare long games)
   - Draw rate > 60% per config (indicates AI can't reach minimum)
